# Web System Menu Restructuring

A comprehensive case study on improving navigation and user experience in a complex web system with over 170 pages and 126 menu items.

## Context

The project aimed to **improve user experience** in a web system with over 170 pages and a complex menu containing more than 120 items across multiple categories. The goal was to reduce navigation difficulties and lack of visual consistency.

## Challenges

- Menu with **126 items** and **18 categories**
- Fragmented structure across **three different fronts**
- Lack of standardization in functionality organization
- Difficulty locating information quickly

## Methods Used

- **Heuristic Analysis** to identify usability issues
- **Complete interface mapping** (Site Map) in Figma
- **Behavior analysis tools** (e.g., Clarity, Datadog) to understand real usage
- **Card Sorting** for category reorganization

## Problem

How can we improve user experience to find functionalities in a system with over 170 pages and reduce the lack of consistency in the front-end?

## Hypotheses

1. **Remove unused pages** to simplify navigation
2. **Reorganize and categorize menus** to reduce searches and increase efficiency

## Actions

- Identification and removal of obsolete screens
- Creation of a new menu structure with more intuitive categories
- Visual standardization of icons and components
- Planning incremental deliveries to avoid impacting current workflows

## Initial Results

- **Reduction of system pages** (e.g., from 35 to 23)
- **Removal of thousands of redundant code lines**
- **Increased test coverage** and reduced duplication
- **Improved perception of organization** by users

## Next Steps

- Continue removing unused pages
- Analyze most accessed items to prioritize improvements
- Test new menu structure with users (Card Sorting + Usability Testing)

## Key Learnings

- The importance of real data to support decisions
- How to break down large deliveries into smaller continuous improvements
- The value of standardization for consistency and scalability

## Timeline

6 months (Research, Analysis, Design, Implementation)

## Role

Product Designer & UX Researcher
