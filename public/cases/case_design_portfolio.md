# Case de Design – Reestruturação de Menu em Sistema Web

## Contexto
O projeto surgiu da necessidade de **melhorar a experiência do usuário** em um sistema web com mais de 170 páginas e um menu complexo, contendo mais de 120 itens distribuídos em diversas categorias. O objetivo era reduzir a dificuldade de navegação e a falta de padronização visual.

## Desafios
- Menu com **126 itens** e **18 categorias**.
- Estrutura fragmentada em **três fronts diferentes**.
- Falta de padrão na organização das funcionalidades.
- Dificuldade para localizar informações rapidamente.

## Métodos Utilizados
- **Análise Heurística** para identificar problemas de usabilidade.
- **Mapeamento completo da interface** (Site Map) no Figma.
- **Ferramentas de análise de comportamento** (ex.: Clarity, Datadog) para entender uso real das telas.
- **Card Sorting** para reorganização das categorias.

## Problema
Como melhorar a experiência dos usuários para encontrar funcionalidades em um sistema com mais de 170 páginas e reduzir a falta de padrão existente no front?

## Hipóteses
1. **Remover páginas não utilizadas** para simplificar a navegação.
2. **Reorganizar e categorizar menus** para reduzir buscas e aumentar eficiência.

## Ações
- Identificação e remoção de telas obsoletas.
- Criação de uma nova estrutura de menu com categorias mais intuitivas.
- Padronização visual dos ícones e componentes.
- Planejamento de entregas incrementais para evitar impacto no fluxo atual.

## Resultados Iniciais
- Redução de páginas no sistema (ex.: de 35 para 23).
- Remoção de milhares de linhas de código redundante.
- Aumento da cobertura de testes e redução de duplicação.
- Melhor percepção de organização pelos usuários.

## Próximos Passos
- Continuar a remoção de páginas não utilizadas.
- Analisar itens mais acessados para priorizar melhorias.
- Testar nova estrutura de menu com usuários (Card Sorting + Testes de Usabilidade).

## Principais Aprendizados
- A importância de dados reais para embasar decisões.
- Como dividir grandes entregas em pequenas melhorias contínuas.
- Valor da padronização para consistência e escalabilidade.

# Design Case – Web System Menu Restructuring

## Context
The project aimed to **improve user experience** in a web system with over 170 pages and a complex menu containing more than 120 items across multiple categories. The goal was to reduce navigation difficulties and lack of visual consistency.

## Challenges
- Menu with **126 items** and **18 categories**.
- Fragmented structure across **three different fronts**.
- Lack of standardization in functionality organization.
- Difficulty locating information quickly.

## Methods Used
- **Heuristic Analysis** to identify usability issues.
- **Complete interface mapping** (Site Map) in Figma.
- **Behavior analysis tools** (e.g., Clarity, Datadog) to understand real usage.
- **Card Sorting** for category reorganization.

## Problem
How can we improve user experience to find functionalities in a system with over 170 pages and reduce the lack of consistency in the front-end?

## Hypotheses
1. **Remove unused pages** to simplify navigation.
2. **Reorganize and categorize menus** to reduce searches and increase efficiency.

## Actions
- Identification and removal of obsolete screens.
- Creation of a new menu structure with more intuitive categories.
- Visual standardization of icons and components.
- Planning incremental deliveries to avoid impacting current workflows.

## Initial Results
- Reduction of system pages (e.g., from 35 to 23).
- Removal of thousands of redundant code lines.
- Increased test coverage and reduced duplication.
- Improved perception of organization by users.

## Next Steps
- Continue removing unused pages.
- Analyze most accessed items to prioritize improvements.
- Test new menu structure with users (Card Sorting + Usability Testing).

## Key Learnings
- The importance of real data to support decisions.
- How to break down large deliveries into smaller continuous improvements.
- The value of standardization for consistency and scalability.
